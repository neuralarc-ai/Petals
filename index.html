01 · The USP

One brain.
Every agent reads it.
Every agent writes it.

Other tools give you tabs. Petals gives you a team — because every CLI works from the same file: PETALS.md, the shared brain that lives inside your project.

PETALS.md
  • 01
    The plan lives thereOne prompt becomes a work distribution — ### Task — Claude Code, one disjoint slice per agent, no collisions by design.
  • 02
    Notes flow through itAgents leave one-line heads-ups on the Updates board — “renamed a function”, “exposed calc() for sci mode” — and skim each other's notes to stay in sync.
  • 03
    Done is declared thereEach agent ends its slice with STATUS: DONE — Petals watches the brain and the terminals, and ticks them off as they land.
  • 04
    It ends with a team noteThe lead integrates, verifies end to end, and writes an Integration report — plus a short note signed by the whole team.
